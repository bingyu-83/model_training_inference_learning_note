H100 关键参数

拐点 = 990 TFLOPS ÷ 3.35 TB/s ≈ 296 FLOP/Byte

左边斜线斜率 = HBM 带宽 3.35 TB/s
水平天花板 = 峰值算力 990 TFLOPS
拐点右边：Tensor Core 跑满，加数据没用
拐点左边：带宽是瓶颈，算力在空等

典型 Kernel 位置

Softmax / LayerNorm~3 FLOP/Bytememory
KV Cache 读取~1 FLOP/Bytememory
Elementwise ops~1 FLOP/Bytememory
GEMV（decode推理）~N/2 FLOP/Bytememory
Flash Attention~100 FLOP/Byte接近拐点
大批量 GEMM>1000 FLOP/Bytecompute

优化方向

● 拐点左边（memory-bound）
减少 HBM 读写次数
→ Kernel Fusion，把中间结果留在 SRAM
→ Flash Attention 分块，不写回整个矩阵
→ 量化（FP8/INT4），同带宽搬更多数

● 拐点右边（compute-bound）
提高 Tensor Core 利用率
→ 更大 tile size，减少 warp 空转
→ 低精度（FP8 算力是 FP16 的 2×）
